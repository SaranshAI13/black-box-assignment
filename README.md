# Black Box Reverse Engineering Assignment

This repository contains my solution for the shipping price engine reverse engineering assignment (`oracle.py`).

## Files Included

- **`my_quote.py`**: Clean Python re-implementation of the pricing engine.
- **`SPEC.md`**: Detailed specification of all pricing rules discovered during testing.
- **`probes.py`**: Investigation script used to test hypotheses against the oracle.
- **`SUMMARY.md`**: Investigation process summary and tested hypotheses.
